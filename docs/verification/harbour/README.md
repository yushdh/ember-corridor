## 帧耗时

Windows，Arcade 3.3.3，RTX 5060 Laptop GPU。逻辑 640×360，窗口 1280×720，最近邻整数倍缩放，开垂直同步，四项反馈设为最高档。每次绘制运行两个 1/120 秒模拟步。每版各有一轮截图，然后再走一遍五室计时。每室 150 帧，舍去前 10 帧，测量段关闭读回。呈现间隔取连续两次窗口翻页完成的时间差，提交时间从模拟更新开始计至绘制调用返回。

| 项目 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 样本数 | 700 | 700 |
| 平均 FPS | 59.51 | 59.61 |
| 呈现间隔 P95 | 17.58 ms | 17.56 ms |
| 呈现间隔 P99 | 18.38 ms | 18.08 ms |
| 更新和绘制提交 P95 | 3.90 ms | 3.90 ms |

数值来自同机每版各一次回放，反映固定镜头下开启垂直同步的表现。GPU 独立耗时、首次载入、长时间运行和低配置硬件未测。[修改前计时](before/timing.json) · [修改后计时](after/timing.json)

## 播放、遮挡与路线

已分别调用正式模块入口及 `--practice`、`--skirmish`，读回三扇窗口的游戏画面。正式入口从标题页按 Enter 进入潮钟线。

- 在窗口绘制后读取当前纹理，覆盖潮光与航标 32 帧、倒影 24 帧、水轮 24 帧和五室装置各 20 帧。逐室确认切房只显示本室装置、场景精灵总数稳定、暂停冻结环境时钟。实际读回的前后各 75 张窗口帧均通过 2×2 像素块检查。[播放计数](after/animation.json)
- 在最高反馈档，蓄焰斩第八帧、铆弩手预警和 10 个战斗粒子同屏。主角面甲、预警图标和横向瞄线可辨认。轻重击接触动画各三帧、守钟人两档受击亮帧均已触发。[实机截图](after/warning-fire.png) · [触发记录](after/overlap.json)
- 原生按键路线走完五室，包含装配、登台扳绞盘、击败守钟人、敲钟、开新局、泵房死亡与重开。使用临时档案。37 项现有测试通过；55 个清单条目与磁盘一一对应。十二张相关背景 PNG 独立重绘后逐文件 SHA-256 一致。[路线数据](after/route.json)
