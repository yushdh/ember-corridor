## 录屏时间线

录屏来自正式 Arcade 窗口。脚本向窗口发送开始、移动、攻击和暂停输入，在 120 Hz 模拟中按 30 fps 读取最终画面，编码为无声 H.264，并完整解码检查。[逐项时间和数值](timeline.json)

| 片段时间 | 实际画面 |
| --- | --- |
| 0.60 秒 | 开始进入退潮门廊。地名淡入，底部只提示移动；行者停在 x=75。 |
| 3.33–3.40 秒 | 移动提示先退场，随后地名完全消失。目标接续短显，之后顶部中央恢复为空。 |
| 6.60–8.87 秒 | 按 D 向盐栈跑去，接近台阶出现跳跃提示。跑到 x=419.7 时，耐力由 100 降至 63.2，生命仍为 100。 |
| 8.90–10.07 秒 | 松开移动键并出刀，耐力回升至 94.47。钩手命中后，生命降至 87。[交锋帧](combat.png) |
| 10.10–12 秒 | 暂停。左侧可看当前目标，右侧仍能看到交战双方。 |

## 复验范围

- 本机 720p 窗口以 640×360 最近邻绘制世界；字体采用 Windows 微软雅黑，按窗口物理像素单独栅格化。截图通过了世界像素块检查。独立实时开局静候 10.308 秒，移动提示在开局后 2.77 秒消失，随后未重现。[静候记录](idle.json)
- 用方向键从标题进入设置，调整一级后核对存档，再回到开始游戏。实测暂停进入角色、设置、改键和重看教程。切换到重锤并切回短刃后，短刃名按时消失。重新进入已经到过的房间，地名没有重播。[角色](character.png) · [设置](settings.png) · [改键](bindings.png) · [武器名](weapon.png)
- 从第一室入口实战到两敌清场，击败一人后目标显示 1/2。到东门用方向键选择回潮轮，Enter 装配成功，永久炉谱写入测试档。[目标变化](progress.png) · [装配](forge.png)
- 用原生 Windows 按键走完种子 17 的五室，扳绞盘、击败守钟人、敲钟，游戏计时 56.55 秒；验证暂停、胜利重开及死亡重开。47 项单元测试通过，包含地面奔跑、耗尽减速、停步恢复、空中与抵墙判定。[路线记录](route.json)

在项目目录运行以下命令可复验菜单、装配和截图。录制另向验证程序提供本机 FFmpeg 的路径；日常游玩无需编码器。

```powershell
.\.venv\Scripts\python.exe -m game --seed 17
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
.\.venv\Scripts\python.exe tools/verify_hud.py
.\.venv\Scripts\python.exe tools/verify_hud.py --forge
.\.venv\Scripts\python.exe tools/verify_hud.py --encoder (Get-Command ffmpeg).Source
```

真人在不同显示器与观看距离下的小字阅读体验、耐力对多局难度的影响及发行包未验证。
