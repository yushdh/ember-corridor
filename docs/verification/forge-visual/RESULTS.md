### 实际帧耗时

Windows 11、RTX 5060 Laptop、OpenGL 4.6、Python 3.12.14、Arcade 3.3.3。1280×720 窗口，垂直同步，目标 60 Hz。两次均将四项反馈设为 3 档。盐炉渡口测试有三名敌人，每次呈现推进两个 1/120 秒的模拟步。先采画面再预热，随后以相同序列测量 864 个呈现间隔。计时阶段关闭截图读回。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 平均 FPS | 59.58 | 59.62 |
| 平均呈现间隔 | 16.78 ms | 16.77 ms |
| P95 / P99 | 17.78 / 19.03 ms | 17.64 / 18.16 ms |
| 更新和绘制提交 P95 | 3.42 ms | 3.44 ms |
| 同屏粒子峰值 / 弩弹峰值 | 13 / 1 | 11 / 1 |

另在潮钟线门廊单测新版蓄焰斩，两名钩手、相同画质，350 个呈现间隔的中位数为 16.74 ms，P95 为 17.70 ms。更新和绘制提交 P95 为 4.33 ms。以上为本机短场景观察值。[修改前原始采样](before/report.json) · [修改后原始采样](after/report.json) · [蓄焰斩采样](after/fire-performance/after-timing.json)

### 播放与回归

检查了清单内 50 份项目文件和三个图集配置里的 213 个帧区域、脚底锚点及武器挂点，非空单元的画面均留在裁边内。窗口实际播完两把武器、双朝向各六组移动动作，以及四招的有效刀光。补查覆盖上挑末段、潮印和八帧倒地。环境动画三组各 12 帧均有播放记录。[移动逐帧记录](after/walk-cycles.json) · [普通接触动画、Boss 受击亮度与音效记录](after/overlap.json)

两版门廊回放都在第 365 个模拟步、第 8 号火刃姿势命中，钩手生命 62 → 8。实测挥空无命中停顿；砍中后停顿 5 个显示帧，14 个技能姿势、4 个爆火帧和三种技能音均播放。37 项逻辑测试通过，五室 Boss、五次装配、胜负重开与存档恢复复验通过。[修改前碰撞](before/fire/capture.json) · [修改后碰撞](after/fire/capture.json) · [关卡回归](after/campaign/route.json)

剩余限制为多敌贴身时身体仍有局部重叠，需同时看头顶徽记。扬声器上的音色与警告音平衡、其他显卡和长时间混战帧耗时未验证。
