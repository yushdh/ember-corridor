# 东门料槽 · 装配前后的数值

在 1280×720 的游戏窗口中，使用相同的门廊、镜头和炉件档位。旧版显示单阶效果，新版同时显示当前炉件、当前武器的首击伤害、潮印完整冷却时间和固定减伤。移到回潮轮时，能看到卸下刃齿带来的刀伤变化。[旧版画面](before/swap.png) · [新版画面](after/swap.png)

| 已有炉件与操作 | 实际首击 | 潮印再次就绪 | 钩手一击掉血 |
| --- | ---: | ---: | ---: |

| 一阶刃齿升二阶，重锤 | 55 | 420 步 / 3.5 秒 | 13 |

四组定点交锋使用独立存档，预设已有炉件、可供领取的匣子与交战距离。方向键预览后先按 Esc，检查匣子可再开且阶数未变，再次进入按 Enter 确认。确认后通过游戏更新读取敌人的实际掉血、从施法到冷却归零的物理步数，以及钩手命中主角的伤害。每步为 1/120 秒。固定减伤显示抵扣点数，单次受击仍有 1 点伤害下限。[重锤升级](after/upgrade.png) · [落锤命中](after/hammer-hit.png) · [甲片](after/armor.png) · [回装](after/refit.png) · [实测数据](after/checks.json)

另外从种子 17 的标题页用 Windows 原生按键开始新局，走完第一室、击败两名守卫，在第一个料匣里看到两种炉件。焦点在刃齿时，按数字 2 直接装入回潮轮；永久档随后收录甲片炉谱。此段没有预设敌人血量、人物位置或炉件。本轮未重跑整条五室。[新档首匣](after/fresh-forge.png)

### 复验

最终 Windows ZIP 在项目外的中文目录解压，使用无 Python 的 PATH 运行。上述新版截图和数值取自包内 EXE，退出码为 0。项目的 53 项测试通过。[安装包校验记录](after/distribution.json)

完整解压 Windows 试玩包后运行以下命令，指定一个尚不存在的输出目录。专项自检自动退出并输出窗口截图与 JSON。源码下可运行 `python tools/verify_forge_preview.py build/forge-preview-check`。手工五室的真人首玩计时与构筑的长期平衡仍待验证。

```powershell
.\EmberCorridor.exe --verify-install .\炉件预览验收 --forge-preview
```
