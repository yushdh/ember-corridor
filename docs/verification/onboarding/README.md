## 两次开局与上下文

- **新档一，静候。** 按 Enter 开始后约 0.02 秒出现移动提示，约 2.78 秒完全消失；持续原地等待 10.31 秒，未再次弹出。录屏从标题页开始，到提示消失后结束。MP4 由原始窗口帧按采样时间合成，已完整解码。[时间记录](idle.json) · [十秒后的窗口](idle-10s.png)
- **新档二，提前操作。** 首个可控步开始向右，提前起跳、挥刀、翻滚。随后行者实际进入台阶、近战距离和敌人前摇的触发条件。四项掌握记录完整，本局弹出次数为零。[熟练路线](expert.json)
- **上下文与持久化。** 另一次沿路前进，依次看到了移动、跳跃、攻击和翻滚提示，前摇出现时翻滚优先。用熟练档重新启动，四项均跳过。暂停后将左移改为 H，再重看教程，键帽显示 H / D；旧 A 未令角色移动，按 H 后向左行走并淡出提示。重看后可再次暂停、打开说明。另在提示可见时分别切房和受到致命伤，均立即清除。[触发时间](context.json) · [改键后提示](replay-H.png) · [操作说明](controls.png) · [清除边界](teardown.json)
- **下一次抬手。** 独立双钩手交锋在第 38 模拟步记录到最后一次命中，第 128 步看到第二名钩手预警。此时上一刀的刀光已关闭、战斗粒子为零，两名守卫的头顶徽记都已绘制。[预警画面](next-warning.png) · [状态记录](warning.json)

## 像素、帧耗时与回归

角色实机位置与朝向保持不动时，隔离绘制人物，比较每个不透明源像素和 640×360 世界缓冲。在 720p、1080p、1366×768 的三个跑步采样，分别有 1514、1642、1515 个像素颜色完全相同。再将完整世界缓冲用最近邻整倍放大，与绘制 UI 前的实际窗口逐像素比较，三种尺寸均相同。720p 为 2×，1080p 为 3×，1366×768 为 2×，左右各留 43 像素、上下各留 24 像素。另检查了窗口 HUD 字形确实包含物理分辨率笔画。[两层采样记录](sizes.json)

Windows 11、RTX 5060 Laptop，1280×720、垂直同步、四项反馈最高档。三敌回放采集 864 个无读回计时帧，平均 59.63 FPS，呈现间隔 P95 为 17.64 ms，P99 为 18.25 ms。43 项逻辑测试通过，旧版炉谱、设置及备份读写均有对应测试。正式游戏、练习与三敌交锋均已打开窗口并进入暂停说明页；另用临时档案完成了装配、五室通关与胜负重开。[帧耗时](performance.json) · [路线数据](route.json)

真人首次接触游戏时的提示阅读速度、其他显卡及显示器上的观感未验证。两次开局均由程序向游戏输入按键。

在项目根目录可用以下命令复验。expert 与 reopen 要使用同一份测试档案。

```powershell
.\.venv\Scripts\python.exe tools\verify_guidance.py idle
.\.venv\Scripts\python.exe tools\verify_guidance.py expert --profile .venv\guidance-check
.\.venv\Scripts\python.exe tools\verify_guidance.py reopen --profile .venv\guidance-check
.\.venv\Scripts\python.exe tools\verify_guidance.py sizes
```
