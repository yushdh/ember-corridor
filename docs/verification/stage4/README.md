## 实际路线

最终一次原生按键路线的游戏内通关用时为 **57.49 秒**。击破 9 名普通守卫和 1 个 Boss，留存 18 张原尺寸截图。运行环境为 Windows 11、RTX 5060 Laptop、Python 3.12.14、Arcade 3.3.3。程序记录到全部五种新增提示音进入播放状态。已知路线的自动通关短于 5–10 分钟的体验目标，真人首玩时长待测。

从标题按 Enter，带着弯刃与重锤进入退潮门廊。沿途使用潮印和锤击清除守卫，在铆雨泵房跳上两座石台，在沉闸水道翻滚过梁，在司钟吊廊先登上层扳绞盘，再前往东门。在潮钟熔庭观察守钟人的低扫、定点喷潮和半血变相，击破后到东端按 E 鸣钟。胜利后按 R 重开，第二局由钩手把行者击倒，再按 R 验证满体力、第一室、技能就绪和无残留弩弹。暂停时检查过战斗时钟停止。

## 复验

本轮另从正式模块入口分别启动并绘制默认关卡、三敌交锋、移动练习。此前的两条实机回归路线也通过了清场与死亡重开、穿低梁及高台往返检查。25 项单元测试、依赖一致性和模块编译检查均通过。

在项目根目录执行以下命令，回放会自行关闭。若需人工复核，可在第四室先试东门，再登上吊廊按 E 操作绞盘，确认门洞打开；在末室观察半血后喷潮的第二道竖向标线。真人首玩用时、扬声器听感以及其他硬件的表现未验证。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v

```
