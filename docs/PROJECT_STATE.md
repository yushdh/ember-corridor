## 运行与操作

潮钟线已追加弯刃专属的蓄焰斩。地面按住 L，约 0.45 秒后刃光骤长，松开时向前踏步挥斩。早松收刀，受创中断。实机在退潮门廊起点挥空，随后前行命中钩手，敌人从 62 血降到 8 血，停顿覆盖 5 个显示帧。蓄焰斩专项交付时 29 项自动测试通过，当时清单含 49 个项目文件，系统字体单列。[实机回放](verification/firecut/firecut.gif) · [同镜头对照与性能](DEVLOG.md#蓄焰斩的实机对照)

在项目根目录运行 `.\.venv\Scripts\python.exe -m game`，按 Enter 开始。使用 `--skirmish` 进入原版三敌交锋，使用 `--practice` 练习移动。

A/D 移动，Space 变高跳，S+Space 下穿，K 翻滚，J 攻击，1/2 换装。潮钟线用 Q 施印、E 开门或操作机关。Esc 暂停，F1–F4 调节反馈。死亡或结算后按 R 重开。两把武器初始均持有，反馈设置跨进程保存。清场后靠近东门前的炉料匣按 E，通过数字键装配或升级，Esc 离开。

本机为 Windows 11 build 26300、RTX 5060 Laptop、OpenGL 4.6。沿用 Python 3.12.14、Arcade 3.3.3、Pillow 11.3.0、pyglet 2.1.19。[依赖锁定](../requirements.txt)
