# 余烬回廊开发日志

## 2026-11-20 · 潮钟线

**接手时。** 盐炉渡口已有两把武器、三类守卫和完整的移动路线。我先运行了原有的 20 项测试，再让原生窗口走过清场、死亡和重开。阶段 3 的多人遮挡仍能复现于上轮对照，已有头顶徽记可读，本轮继续搭建手工关卡。

**为什么做吊廊。** 把五间房简单串成五场平地战，用不到前面几轮做的垂直移动。我把第二间的铆弩手放上实体泵台，第三间留出只够翻滚的闸底，第四间把绞盘装在上层吊廊。门和绞盘都用 E，只有靠近相应高度才能操作。武器、体力与潮印冷却随过门继承，伤害判定和碰撞共用该房间自己的地形。

**给守钟人两种可读的攻击。** 铜钟外壳、偏向一侧的钟槌和胸前炉栅构成守钟人的轮廓。低扫在地面推进刻线，喷潮在玩家原位置立起竖向边界。锁定后可以撤开。半血时守钟人先停手鸣钟，然后缩短准备时间，并在喷潮的逃离方向多锁一处。Q 潮印从手部推出青绿色窄波，能击散同高度的弩弹，实体墙挡住它。

**第一次实机检查。** 潮印释放时，旧的整数像素断言失败。检查绘制路径后发现新增的斜边直接在 1280×720 帧缓冲光栅化，不能保证每个逻辑像素对应完整的 2×2 色块。我把潮印、钟槌扫击和蒸汽柱改为原生分辨率的六帧透明图集。后续的实机检查继续使用原先的像素断言。

**走完整条路。** 第一次走吊廊，驱动脚本先追了远端的重卫，又从下层直奔高处绞盘。我把按键路线改成沿石座上行，从绞盘旁经过时先扳再走。另一次在泵台前受击，驱动一直按着空格，恢复后仍没有新的起跳按下事件。我让驱动在落地后松开并重新按下，游戏继续沿用原有跳跃规则。两条修复都保留真实的移动距离和攻击窗口。

**看完截图再收尾。** 守钟人二次举槌时贴到了图集顶边，倒地时钟壳又沉入了脚底线。我重排腕和躯干的位置，核对 16 个单元的非透明边界、挂点与落脚。结算画面一度仍提示再次按 E，最后把这个提示限定在游玩期间。原版三敌交锋和练习模式也各自重新走过一遍。

**留给下一轮。** 已知路线的自动通关约一分钟，比原定 5–10 分钟短。下一次真人首玩应分别记录在泵台、吊廊和 Boss 的停留时间与重试次数，再决定应当增加哪一段的探索或交锋。外放音效的层次仍待试听。
